6- There is a problem in server while uploading the profile image. currently it has been rectified by the AI on vps, but it has given a message for you:

Bug Fix: Profile Image Upload in Multi-Tenancy

The Bug

File: src/controllers/userController.js
Line: 94

Problem: When uploading profile images, the code was calling uploadFile() with the wrong parameter:

// WRONG - passing req object as bucket name
const uploadResult = await uploadFile(file, 'profiles', req);

Function signatures:
// uploadFile expects: (file, folder, bucketString)
async function uploadFile(file, folder, bucket = null)

// uploadTenantFile expects: (file, folder, reqObject)  
async function uploadTenantFile(file, folder, req)

The uploadFile function tried to use req (an object) as the bucket name, resulting in:
MinIO upload error: InvalidBucketNameError: Invalid bucket name: [object Object]

The Fix

Change the import:
// Before
const { uploadFile } = require('../services/uploadService');

// After
const { uploadTenantFile } = require('../services/uploadService');

Change the function call:
// Before (line 94)
const uploadResult = await uploadFile(file, 'profiles', req);

// After
const uploadResult = await uploadTenantFile(file, 'profiles', req);

Why This Happened

The codebase has two upload functions:
- uploadFile(file, folder, bucket) - For direct uploads with explicit bucket name
- uploadTenantFile(file, folder, req) - For multi-tenant uploads that extract bucket from req.tenant.bucket

The userController.js was using the wrong function for the multi-tenant context.
